# Currency Converter API

Бэкенд-приложение для конвертации валют. Является прослойкой между клиентским приложением и сторонними API, предоставляющими информацию о курсах валют.

## Стек технологий
- **Node.js** (LTS)
- **TypeScript**
- **Express**
- **Supabase** (PostgreSQL)
- **Axios**
- **Swagger** (документация)
